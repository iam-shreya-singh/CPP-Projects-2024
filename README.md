To-Do List App (Console-Based in C++)

--> A simple yet efficient console-based task management application built in C++, designed to help users manage their daily tasks directly from the terminal. This project focuses on implementing core data structures and algorithms to demonstrate practical C++ skills.

**Features**
--> Add, view, and delete tasks

--> Mark tasks as completed

--> Display pending and completed tasks separately

--> Console-friendly, lightweight UI

**Technologies Used**
Language: C++
Compiler: g++ / Visual Studio
Platform: Console (CLI)

**Key Concepts Practiced**
--> Object-Oriented Programming (OOP) in C++
--> Custom implementation of data structures
--> Basic algorithms for list manipulation
--> File handling (for storing task data locally)
--> Clean CLI-based interaction
